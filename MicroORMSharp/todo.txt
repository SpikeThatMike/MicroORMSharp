Retry policy methods
- For transient exceptions in database operations
- These methods can be used to implement retry logic in case of transient failures, such as network issues or temporary unavailability of the database.
- Defaults to 0 retries but can be set per DbQuery ".SetRetryPolicy()" (overrides global if specified) or globally for all queries Database.UseRetryPolicy(3);

Pagination methods
- For paginating query results
- Add onto a DbQuery to specify pagination parameters, such as page number and page size .SetPagination(pageNumber: 2, pageSize: 10);
- This will use OFFSET AND LIMIT

Database Transaction wrapper
- For executing multiple operations within a transaction without the user having to manage the transaction scope manually
- Returns true or false if the transaction was successful or not, and rolls back if any operation fails from an internal try catch block
- var result = await Database.WithTransaction(async trans => { await customer.InsertAsync(trans); await customer.UpdateAsync(trans); });

Map the data into a different class
- For mapping query results into a different class than the entity class
- Add onto DbQuery, SelectTo method which will allow the user to specifiy what the data should map to.
- .SelectTo(x => new CustomerTest { Name = x.Forename + " " + x.Surname })
